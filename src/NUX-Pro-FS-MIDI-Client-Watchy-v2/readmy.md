# NUX BLE-MIDI Footswitch для Watchy v2.0

Отдельная прошивка для Watchy v2.0 на ESP32-PICO-D4. Подключается к NUX
MIGHTY PLUG PRO по BLE-MIDI и назначает один из семи preset каждой из четырёх
кнопок. Настройки хранятся в NVS.

Начальная версия прошивки — `v0.1.0`. Она отображается в шапке экрана и при
старте в Serial Monitor. Единое значение находится в `FirmwareVersion.h`:
обновляйте его при выпуске новой версии. Ревизия платы Watchy v2.0 указывается
отдельно и не является версией прошивки.

## Управление

| Кнопка | GPIO Watchy v2.0 | Короткое нажатие по умолчанию |
| --- | ---: | --- |
| MENU | 26 | Preset 1 |
| BACK | 25 | Preset 2 |
| UP | 35 | Preset 3 |
| DOWN | 4 | Preset 4 |

Одиночное нажатие отправляет назначенный кнопке preset. После отпускания
устройство ждёт 350 мс на возможное двойное нажатие. Для каждой кнопки в
`/settings` задаётся отдельная реакция: выключить double-click, циклически
выбрать следующий preset 1–7 или отправлять выбранный фиксированный preset.
Цикл остаётся действием по умолчанию и сохраняет новое назначение в NVS.

Удерживайте **MENU 2 секунды**, затем отпустите кнопку, чтобы перевести часы
в глубокий сон. Любая из четырёх кнопок будит ESP32; удержанная при пробуждении
кнопка не считается нажатием. Во время сна BLE отключён, после пробуждения
прошивка запускается заново и подключается к NUX. Перед сном экран показывает
монохромный рисунок спящего зверька на подушке с надписью `DEEP SLEEP`; он
остаётся на e-paper, пока устройство спит.

На экране кнопки расположены по корпусу часов: **P1** слева внизу, **P2**
слева вверху, **P3** справа вверху, **P4** справа внизу. Рядом с меткой показан
preset короткого нажатия, строка `2x->N` показывает preset двойного нажатия;
`2x:OFF` означает, что double-click отключён.

Все preset можно переназначить в веб-интерфейсе. Допустимые номера — 1–7.
NUX получает MIDI `Program Change` на канале 1: preset 1–7 соответствуют
значениям 0–6.

У Watchy v2.0 кнопки активны по HIGH. Используются `INPUT` и штатные
аппаратные подтяжки платы; внешние кнопки и `INPUT_PULLUP` не нужны.

Удерживайте **BACK не менее 1,6 секунды**, чтобы включить или выключить
настройки/OTA. Короткое нажатие BACK, напротив, отправляет назначенный ему
preset. Точка доступа автоматически выключается после трёх минут без
запросов. При выключенной точке доступа WiFi-радио отключено.

## Веб-интерфейс и OTA

После удержания BACK подключитесь к сети:

- WiFi SSID: `NUX-Watchy-Setup`
- WiFi password: `nux12345`
- Адрес: <http://192.168.4.1/>
- HTTP Basic Auth: `admin` / `nux12345`

При активной точке доступа экран также показывает SSID, пароль и адрес.
Пароль отображается открыто, как запрошено.

Страницы:

- `/settings` — версия FW, BLE-цель, preset короткого нажатия и режим double-click
  для каждой кнопки;
- `/update` — загрузка файла приложения `.bin`;
- `/save` — обработчик сохранения настроек.

После сохранения настроек устройство перезапустится, чтобы BLE-клиент
использовал новый target. При старте точки доступа SSID, пароль, адрес и
учётные данные выводятся в Serial Monitor.

Учётные данные по умолчанию зашиты в прошивку и не меняются с веб-страницы.
Перед использованием в общей или недоверенной среде замените `AP_PASSWORD`,
`WEB_USERNAME` и `WEB_PASSWORD` в `WatchyConfig.h` и загрузите новую прошивку.
HTTP Basic Auth работает поверх обычного HTTP без шифрования; используйте
интерфейс только в доверенной WiFi-среде.

### OTA-прошивка

1. Сначала загрузите прошивку через USB.
2. В Arduino IDE выберите **Sketch → Export Compiled Binary**.
3. На Watchy удерживайте BACK 1,6 секунды, подключитесь к его точке доступа
   и откройте `/update`.
4. Введите учётные данные и выберите скомпилированный файл приложения
   `NUX-Pro-FS-MIDI-Client-Watchy-v2.ino.bin`.
5. Не отключайте питание до автоматического перезапуска.

Для OTA нужна таблица разделов с двумя OTA-слотами. Выберите
`Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)`, а не `Huge App`:
`Huge App` оставляет один большой раздел приложения и не поддерживает OTA.
Для ESP32 core 2.0.17 компилятор сообщает, что скетч использует 1 187 001 байт
(60% лимита слота 1 966 080 байт); это помещается в OTA-раздел. Другие версии
библиотек и компилятора могут немного изменить размер.

## Arduino IDE

Настройки ниже относятся к **Watchy v2.0**, а не к Watchy V1/V1.5 и не к
обычному ESP32 Dev Module.

### Пакет платы

1. Установите Arduino IDE 2.x.
2. Откройте **File → Preferences** и добавьте в **Additional Board Manager
   URLs**:

   `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`

3. В **Tools → Board → Boards Manager** найдите `esp32` и установите пакет
   **esp32 by Espressif Systems** версии **2.0.17**. Для этой версии скетча
   используйте ESP32 Arduino core 2.0.17; переход на core 3.x требует отдельной
   проверки совместимости BLE-MIDI и Watchy.
4. В **Tools → Board** выберите **ESP32 Arduino → Watchy**.
5. В **Tools → Board Revision** выберите **Watchy v2.0**.
6. В **Tools → Partition Scheme** выберите
   **Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**.
7. Оставьте прочие параметры платы по умолчанию. Убедитесь, что выбран USB
   serial-порт самого Watchy.

Официальная legacy-инструкция Watchy для обычных watch-face примеров предлагает
`Huge App`. Для этой прошивки это значение нужно заменить на OTA-capable
таблицу разделов, иначе загрузка обновлений через `/update` не заработает.

### Библиотеки

Установите через **Sketch → Include Library → Manage Libraries**:

- `BLE-MIDI` от lathoub — версия 2.2.0;
- `MIDI Library` от FortySevenEffects — версия 5.0.2;
- `NimBLE-Arduino` — версия 1.4.3;
- `GxEPD2` от Jean-Marc Zingg — версия 1.6.9;
- `Adafruit GFX Library` — версия 1.12.6 и `Adafruit BusIO` 1.17.4.

Для client-транспорта BLE-MIDI требуется `NimBLE-Arduino` 1.4.3: ветка 2.x
удалила API, используемый `BLEMIDI_Client_ESP32`. Библиотека `Watchy` для этого
скетча не нужна: экран запускается через GxEPD2 напрямую, без `Watchy::init()`.

### Открытие и загрузка

1. Откройте в Arduino IDE папку
   `src/NUX-Pro-FS-MIDI-Client-Watchy-v2` либо файл
   `NUX-Pro-FS-MIDI-Client-Watchy-v2.ino` из этой папки.
2. Подключите Watchy USB-кабелем с передачей данных и выберите его
   последовательный порт. На Windows при отсутствии порта установите драйвер
   Silicon Labs CP210x.
3. Нажмите **Verify**. Проверьте, что результат компиляции меньше лимита
   OTA-раздела — примерно 1.9 MB.
4. Нажмите **Upload** для первой прошивки через USB. Откройте Serial Monitor
   на скорости **115200 baud**: устройство печатает карту кнопок, текущий BLE
   target и события соединения.

Если порт не появился, проверьте USB-кабель и драйвер CP210x. Если загрузка не
начинается, переподключите Watchy и повторите попытку; на Watchy v2.0 USB-UART
обычно автоматически переводит ESP32 в режим загрузчика.

## Экран и энергопотребление

Экран 200×200 управляется напрямую через `GxEPD2_154_D67`, с контактами
Watchy v2.0: `CS=5`, `DC=10`, `RESET=9`, `BUSY=19`, `SCK=18`, `MOSI=23`.
При каждом обновлении целиком перерисовываются шапка, состояние BLE, метки
P1–P4, текущий preset и нижняя строка. Обычные изменения обновляют всю площадь
экрана частичной waveform; полный refresh выполняется при запуске, изменении
режима точки доступа и каждые пять минут. Изображение сохраняется без питания
панели. Уровень батареи показывается в виде индикатора с четырьмя полосами и
цифрового процента.

Для Watchy v2.0 батарея измеряется через GPIO34 и штатный делитель 1:2.
Процент оценивается по напряжению LiPo, поэтому это ориентир, а не точный
измеритель остаточной ёмкости.

Для уменьшения потребления прошивка:

- не запускает RTC, BMA423, функции циферблата и синхронизацию времени;
- считывает батарейный ADC только при обновлении экрана и оставляет вибромотор
  выключенным;
- держит WiFi AP выключенной до удержания BACK и закрывает её по таймауту;
- поддерживает глубокий сон по удержанию MENU; пробуждение происходит по HIGH
  на любой кнопке через RTC GPIO, при этом BLE-соединение разрывается и
  восстанавливается после старта; перед сном на экране появляется заставка
  `DEEP SLEEP`.

В обычном активном режиме BLE остаётся включённым и расходует заряд. Глубокий
сон снижает расход, но разрывает BLE-соединение; после пробуждения Watchy
повторно подключается к педали.

При подключении отправляется SysEx-запрос текущего preset, а экран также
обновляется по входящим MIDI Program Change и известному ответу NUX. Ответ
устройства на этот частный SysEx-запрос аппаратно не подтверждён; основное
переключение preset через Program Change работает независимо от него.
